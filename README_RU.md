# Bambuddy — импорт из MakerWorld

Русская версия расширения Chrome для отправки профиля печати с MakerWorld в библиотеку Bambuddy. Основана на [Bambuddy-Extension](https://github.com/wolfrage76/Bambuddy-Extension) от wolfrage76.

## Установка

1. Распакуйте архив с расширением.
2. Откройте `chrome://extensions/` в Chrome.
3. Включите режим разработчика и нажмите «Загрузить распакованное расширение».
4. Выберите папку, в которой находится `manifest.json`.

## Настройка

Откройте настройки расширения. Укажите основной адрес вашего Bambuddy и API-ключ. Для ключа в Bambuddy включите разрешения `Manage Library` и `Allow cloud access`. Учётная запись Bambu Cloud должна быть подключена в настройках Bambuddy. Нажмите «Проверить подключение», затем «Сохранить» и разрешите доступ расширения к указанному адресу.

## Использование

Откройте страницу модели на makerworld.com. В правом нижнем углу появится кнопка «В Bambuddy». Нажмите её, проверьте выбранный профиль печати и нажмите «Отправить в Bambuddy». При выборе другого профиля на MakerWorld список расширения переключится на него, если вы ещё не выбрали профиль вручную в списке. Отправляется только указанный профиль.

Прежний способ через значок расширения на панели Chrome тоже работает. Если профиль уже есть в библиотеке, расширение покажет уведомление о дубликате.

Название модели и профилей поступает из MakerWorld и сохраняется на языке источника. Сообщения об ошибках, возвращаемые сервером Bambuddy, также могут отображаться на языке сервера.
