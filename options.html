Импорт в Bambuddy
Настройки расширения и подключения к Bambuddy
Подключение
Укажите основной адрес Bambuddy без косой черты в конце. Для адресов в локальной сети используйте http://.
Необходимые разрешения: Manage Library и Allow cloud access. Инструкция по созданию ключа приведена ниже.

Как создать API-ключ
1
Откройте Bambuddy и перейдите в раздел Settings → API Keys («Настройки → API-ключи»).
2
Нажмите Create API Key («Создать API-ключ») и задайте имя, например «Расширение Chrome».
3
Включите Manage Library — это разрешение нужно для сохранения и импорта моделей из MakerWorld.
4
Также включите Allow cloud access, чтобы Bambuddy мог использовать токен Bambu Cloud при загрузке из MakerWorld.
5
Убедитесь, что учётная запись Bambu Cloud подключена в разделе Settings → Bambu Cloud («Настройки → Bambu Cloud»). Её токен используется для всех загрузок из MakerWorld.
6
Скопируйте ключ (он показывается только один раз), вставьте его выше и сохраните настройки.
Советы по использованию
Если перед открытием расширения выбрать профиль печати на MakerWorld, в адресе появится #profileId-XXXXX. Этот профиль будет выбран автоматически.
Уже импортированные профили помечаются значком ✓ в списке. При повторном импорте Bambuddy сообщит о дубликате.
Токены Bambu Cloud действуют около 90 дней. Если при импорте появляется сообщение «requires a Bambu Cloud login», войдите снова в разделе Settings → Bambu Cloud в Bambuddy.
